## AI commit messages

- `/repo commit generate` uses the selected local Codex or Claude Code CLI to generate a message suited to the change: a subject alone for a simple change, or a subject and body when explanation helps, then opens the editable message. `Ctrl+R` generates; press it again to cancel. Generation does not stage, commit or push.
- `/settings` shows the switch, agent, model and complete prompt together in its AI group; only the switch remains when disabled. `/settings ai` focuses that group without opening a submenu. Tools are found only in the current `PATH`; install and log in first. `/settings ai agent [codex|claude]` selects an agent by parameter; A space opens supported names with the current value marked; ↑↓ selects, Tab completes without saving, and Enter saves the choice. Each agent keeps its own model. An unspecified model is shown as `Default` and inherits the CLI model; its command entry also shows the current value. `/settings ai prompt` opens a multiline editor: `Ctrl+S` saves and `Esc` discards edits. Saving replaces the complete default prompt.
- Turn off “Enable AI” in general settings to hide AI commands (including `/settings ai`), generation hints and this help section. Only the general-settings switch can enable AI again; no command enables it.
- The complete prompt is sent with separate context containing the staged patch, five recent subjects and UI language; the default prompt follows that language. Neither a single-line limit nor a body or fixed template is imposed. Staged changes are above the message editor. A horizontal action bar offers Commit, Back and Regenerate, in that order. `Enter` inserts a newline in the editor and `↑↓` moves its cursor. `Shift+Tab` switches between the editor and options; on the action bar, `←→` selects, `Enter` runs the selection and `↑` returns to editing. Selecting Commit executes it directly, without another preview; `Ctrl+S` also commits. The complete body is preserved. Patches over 128 KiB are rejected. Generation streams real text into a read-only preview, with editing and committing locked until completion. Only Cancel generation is offered while generating; `Enter`, `Ctrl+R` or `Esc` cancels; cancellation or failure restores the original draft. Generation has a 120-second timeout. The agent uses its configured model service.

## AI commit composition

- `/repo compose` plans a sequence from staged and non-ignored working-tree changes, independently of single-message generation. Ordinary text changes are split into diff hunks; a hunk is indivisible. Added/deleted files, renames and binary changes are whole units.
- The command opens composition immediately with a spinner. Failures stay on the page; Enter retries and Esc cancels and returns. Results update saved waiting pages without taking over another view.
- `↑↓` selects, `/focus` switches between commits and units, and `Enter` edits the message in place. `Ctrl+S` saves and `Esc` discards edits. `/` opens the `/repo compose` context.
- `message` edits the message; `up`/`down` reorders; `merge` combines with the next commit; `split` puts the selected unit in a new commit; `move` uses arrows and Enter to reassign it.
- `commit` confirms and executes the next item; `regenerate` reads the current repository again. Each step preserves other staging and remaining worktree changes. Changed HEAD, index or contents require a new plan. Completed commits are retained; hooks changing committed contents stop the sequence and report it.
- Composition shares the configured AI agent/model, but has a separate structured prompt. Disabling AI hides its commands. Plans live in this TUI session; restart requires regeneration, while commits and task records persist.
