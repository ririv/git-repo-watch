## 快速导航
- `↑↓` 选择项目，`PgUp` / `PgDn` 翻页。
- 输入为空时，`→` / `Enter` 进入选中项，`←` / `Esc` 返回上一级。
- 有文字时，`←→` 移动光标；`Esc` 先清空输入。
- `Tab` 循环切换仓库、通用设置和定时任务。
- `F1` / `/help` 打开本页，`Ctrl+C` / `/quit` 退出。

## 仓库面板
- 进入仓库后，同时显示概览、分支、工作区文件和提交历史图。
- `/repo branch` 始终打开完整分支视图；输入名称搜索，`Tab` / `Shift+Tab` 筛选全部／本地／远程。
- 分支中 `Enter` 查看引用、提交和上游详情；`*` 标记当前分支，领先／落后基于本地引用，不执行 fetch 或分支写入。
- `Ctrl+S` / `Ctrl+D` 聚焦上个／下个面板，也可点击或在面板内滚动来聚焦。
- `Ctrl+F` 切换当前面板全屏与组合布局。
- 全屏时仍可切换面板，选择、筛选与滚动位置会保留；输入和命令栏始终可用。
- 全屏面板中，`Esc` 先清空输入，再恢复布局；diff 与提交详情仍按原有方式返回。

## 搜索与命令
- 中文界面默认也可用 `、` 打开命令菜单，沿用当前上下文并显示标准 `/`；`、、` 可进入全局命令。设置中选中“输入 、 打开命令菜单”，按 Enter 直接切换并保存，无需确认；英文界面隐藏且不启用。路径、提交信息等正文中的顿号保持原样。
- 直接打字搜索仓库；文件面板中搜索文件，输入框始终可用。
- 搜索栏为空时 `/` 打开当前视图的全宽命令菜单，`↑↓` 选择、`Tab` 补全、`Enter` 进入；`//` 直接打开全局命令。
- 命令支持按名称或中英文提示说明筛选，英文不区分大小写，如 `/终端`、`/频率`、`/live diff`；名称匹配优先，Tab 补全选中项的实际命令。
- 全局菜单只展示顶层命令；输入 `/repo diff` 等前缀即显示所有匹配的子命令，不必先输入空格。父命令排在前面。
- 带参数命令直接在输入栏填写，如 `/repos add <path>`、`/settings concurrency <count>`。
- `Ctrl+U` 清空光标前文字，`Ctrl+A` / `Ctrl+E` 跳到开头／末尾。
- 仓库首页用 `/repos filter` 筛选、`/repos sort` 排序；按 Enter 展开选项，`↑↓` 选择，Enter 应用，Esc 关闭，✓ 标记当前选项。
- 筛选：all 全部、problems 问题、clean 正常、failed 检查失败、unchecked 未检查、no-upstream 无上游、pushes 有推送记录。
- 排序：priority 状态优先、name 名称升序、path 路径升序、updated 最近更新（未检查排最后）；可直接执行，如 `/repos sort name`。
- 筛选与文字搜索同时生效；首页已有搜索时按 `/` 打开命令，应用或关闭后恢复搜索，保留仍可见的选中仓库。只影响当前会话，不检查仓库或修改报告。
- `Ctrl+R` 重新读取报告或刷新文件面板；仓库主列表中的滚轮每次移动三项。

## 上下文前缀
- `/repo diff`、`/repo log`、`/repo branch`、`/repo stash` 打开完整视图；返回恢复来源焦点和选择。子面板中按 `/` 只提供焦点上下文，不改变布局。设置、定时任务和帮助返回时也恢复来源。
- 当前视图前缀独立显示且不能作为文字删除：文件／差异为 /repo diff，历史为 /repo log，分支为 /repo branch，管理页为 /repos、/settings、/schedule。首页使用全局 /，概览使用 /repo，stash 使用 /repo stash。
- 只输入前缀后的操作，如 diff 中的 stage、unstage、layout、refresh；候选只在当前范围内按名称或中英文说明筛选。
- 后缀为空时，第一次 Backspace 选中整个前缀，沿用原来的反色显示，上方候选与全局 / 菜单一致；上下键选择、Tab 补全或点击候选可替换前缀。此时键入或粘贴直接替换为全局命令，保留一个 /；Enter 或 → 保留原前缀，不执行候选。第二次 Backspace 关闭命令并恢复当前视图的搜索；Esc 关闭命令并恢复搜索。
- 空命令后缀再按 / 也会切到全局；从搜索状态输入 //settings 可直接打开全局设置。
- 清除前缀不离开视图或切换仓库，输入期间范围固定；Esc 恢复原搜索，下次打开才按当前焦点重新确定前缀。
- 已有搜索时可先 Home 再 / 打开命令，路径中间的 / 仍作为搜索文字。
- 历史差异提供布局与复制，不提供工作区暂存或刷新；目录补全、配置确认及布局选择器返回后保留前缀、草稿和光标。

## 复制当前选择
- 当前范围按 `/` 后输入 `copy`；候选标签显示实际内容。没有全局复制分组，仓库列表可输入 `/repo copy` 复制仓库完整路径。
- 文件列表的 `/repo diff copy` 复制勾选路径，未勾选则复制当前行；多项按行分隔、路径去重，使用相对路径并保留中文与空格。
- diff 预览的 `/repo diff copy` 复制当前文件的原始补丁；不包含展示行号、颜色或布局换行，不重新读取 Git。
- 历史图的 `/repo log copy` 复制完整提交 ID；提交详情中则复制当前历史文件路径，进入历史 diff 后使用 `/repo diff copy`。
- 分支中的 `/repo branch copy` 复制选中分支名称；错误页按 `/` 显示 /error，执行 copy 复制完整错误。
- 组合面板跟随焦点；读取失败的预览或面板复制其错误详情。打开命令时固定仓库和选择，后台刷新不会改变复制目标。
- 图片、尚未加载、空白或已截断的补丁明确报错；剪贴板后台写入，成功后才提示，不阻塞导航，也不覆盖新命令。
- Linux 需 X11 或支持 data-control 的 Wayland 会话；退出后保留剪贴板内容取决于桌面剪贴板管理器。错误页只开放复制与退出命令。

## 路径与补全
- `Tab` 补全光标处的一级目录；唯一匹配补全并追加 `/`，多个匹配显示目录候选。
- 候选中用 `↑↓` / `Tab` / `Shift+Tab` 选择，`Enter` 填入目录后继续编辑，`Esc` 关闭候选。
- `~`、`~/…` 使用当前用户主目录，与应用数据目录无关；确认和执行使用绝对路径。
- 空格和中文按字面处理，可用匹配的单／双引号包裹整段路径，包括 `~/…`。
- 隐藏目录需先输入 `.`；补全仅读取一级目录，并保留光标后的路径。
> 路径是命令后的整段参数。不展开变量、通配符或 Shell 转义；不支持 ~user 用户路径。

## 分支、拉取与 stash
- `/repo branch create <name>` 在当前提交创建本地分支，不切换；`/repo branch switch <name>` 切换已有本地分支。切换前要求已跟踪文件干净，不覆盖未跟踪文件，也不切换其他 worktree 占用的分支。
- `/repo fetch` 立即在后台获取已配置的远程跟踪分支，遵守 refspec、排除与 skipFetchAll 设置，不改工作区或推送。
- `/repo pull` 获取一次远程，预览固定的上游提交，确认后仅快进；分叉或脏工作区明确报错，不自动 merge、rebase 或 stash。
- `/repo stash` 打开独立列表；↑↓选择、Enter 查看详情、←/Esc 返回。进入后 `/` 使用 /repo stash 上下文，列表可搜索消息和对象 ID。
- `/repo stash save <message>` 保存已跟踪变更；`/repo stash save-all <message>` 也包含未跟踪文件，均不包含忽略文件。
- `/repo stash apply <stash-id>` 恢复并保留；`/repo stash pop <stash-id>` 恢复成功后删除；`/repo stash drop <stash-id>` 只删除，不恢复。选中列表项后补全这些命令会填入其完整对象 ID，仍需确认。
- `/repo stash copy` 复制选中 stash 的完整对象 ID；`/repo stash refresh` 刷新列表。恢复发生冲突时报告失败，保留原 stash 与实际冲突状态。
- 写操作先预览再确认，返回编辑保留完整草稿。确认时重新核验 HEAD、索引、工作区和目标引用；stash 还核验列表顺序，外部变更会要求重新预览。

## 文件、提交与推送
- `/repo diff` 打开统一变更界面，同时显示未暂存、已暂存文件及文本／图片预览；选择文件后在后台读取对应版本。
- 宽屏左右排列，窄屏上下排列；`Tab` / `Ctrl+S` / `Ctrl+D` 切换焦点，`Enter` / `→` 聚焦预览，`Ctrl+F` 放大当前面板。
- `Esc` 先清空输入，再恢复放大布局、返回文件焦点；再次按下返回仓库工作区或仓库列表。
- 差异默认在宽屏使用左右对比，窄屏使用统一视图；两侧同步滚动，长行换行后仍保持对应。
- `/repo diff layout` 打开横向选择器并定位当前设置；`←→` / `Tab` / `Shift+Tab` 切换候选，`Enter` 应用，`Esc` 返回命令草稿。鼠标点击选项只移动候选，仍按 Enter 应用。
- 命令列表标记当前选项，自动模式还显示当前实际的统一／双栏视图，并随窗口大小更新；可点击候选行或按 `Enter` 进入。
- `/repo diff layout auto`、`/repo diff layout split`、`/repo diff layout unified` 立即切换布局，本次 TUI 会话生效；`Tab` 可补全子命令。
- 空输入时 `Space` 勾选，`Insert` 始终勾选，`Ctrl+A` 勾选全部可见项；筛选隐藏文件时保留勾选。
- `/repo diff stage` / `Alt+S` 暂存全部勾选项，`/repo diff unstage` / `Alt+U` 取消暂存；未勾选时作用于光标文件。必须先明确选择文件，操作命令不再兼任打开页面。
- 暂存仅接受未暂存项，取消暂存仅接受已暂存项；跨组勾选会明确报错，不修改索引。完成后只刷新当前仓库，保留焦点和新命令草稿。
- 取消暂存保留工作区内容，Git 忽略的文件不列出。
- `/repo commit` 预览暂存内容，输入说明并确认；保留 Git 钩子和签名。
- `/repo push` 获取远程并核验上游，确认后仅推送预览过的当前分支快照。
- `/repo terminal` 在选中仓库打开系统默认终端，可输入 `/te` 后按 `Tab` 补全。

## 图片预览
- 在 `/repo diff` 中选中 PNG、JPEG、WebP 即预览前后版本；历史详情仍按 `Enter` 查看。按内容识别，不依赖扩展名。
- 宽屏左右对照，窄屏且高度足够时上下排列；较矮面板保留左右对照。保持比例；透明部分显示棋盘背景。
- `Esc` 返回，窗口缩放自动调整；缺失版本、损坏图片和终端不支持像素会明确提示。
- 暂存区与历史图片读取 Git 对象，不用当前磁盘内容代替历史版本。

## 提交历史图
- `/repo log` 读取本地分支、远程跟踪分支、标签和 HEAD，不进行 fetch。
- `↑↓` / `PgUp` / `PgDn` 选择；`Enter` 进入提交详情，再进入历史文件差异；空输入时 `←` 返回。
- 每页最多 100 个提交，在末尾按 `↓` 或执行 `/repo log more` 继续加载；`Ctrl+R` 更新引用快照。
- 输入哈希、标题、作者或引用名称定位已加载提交；图节点始终保留，`Tab` / `Shift+Tab` 选择下个／上个匹配。
- `Alt+←→` 平移过宽的图；宽屏显示提交元数据预览。
- 详情中输入文字筛选文件，`Tab` 切换合并提交的父提交，`PgUp` / `PgDn` 滚动提交信息和说明。
- 根提交与空树比较，其他差异明确标出父提交和当前提交；`/repo diff` 布局命令同样生效。
> 图和历史差异读取不暂存、不提交、不 fetch、不推送，也不改变检查报告。

## 检查与配置
- `/repo check` 检查当前仓库，`/repos check` 检查全部注册仓库；直接开始，无需确认，也不推送。
- 检查在后台进行，可继续浏览、搜索和查看文件；旋转标记指示正在检查的仓库，未完成的保留上轮状态。
- `/cancel` 优先取消当前仓库任务，无当前任务时取消整轮检查；独立仓库并行，共享 Git 存储的操作串行。配置读改写使用短事务。
- `/repo` 打开选中仓库的概览，所有仓库视图和操作归入其下；`/repos` 返回仓库列表，`/repos manage` 查看注册和排除配置；也可直接使用：`/repos add <path>`、`/repos remove`、`/repos exclude <path>`、`/repos unexclude <path>`。
- `/repos scan <path>` 预览发现结果，`/repos import <path>` 注册发现的仓库；扫描遵守 Git 忽略规则。
- `/settings concurrency <count>` 设置有界并发数，范围为 1 至 32。
- `/settings startup-check <true|false>` 控制启动时检查全部仓库，默认 true；修改在下次启动生效。
- `/schedule` 打开任务管理页，查看状态和待应用间隔、修改配置并启停任务。
- `/schedule interval <duration>` 设置间隔，如 6h；`/schedule autopush <policy>` 接受 disabled 或 fast_forward。
- `/schedule anchor <datetime|auto>` 设置本地时间基准，可填 HH:MM[:SS] 或 YYYY-MM-DD HH:MM[:SS]；auto 在启用时重新生成。
- 基准缺省时，首次启用会自动生成并保存，后续启停和重启沿用；定时任务页显示基准与当前已应用任务的下次触发。
- 间隔支持 s / m / h / d / w（秒、分、小时、天、周，至少 60 秒），保存后用 `/schedule apply` 应用。
- `/schedule apply` 应用配置，`/schedule enable` 启用任务，`/schedule disable` 停止后续调度。
> 自动推送只用于定时检查。启动 TUI 默认后台检查全部仓库，可在通用设置中关闭；不会扫描或推送。启动检查完成后更新整轮报告；暂存、提交和推送只根据本地 Git 状态刷新对应仓库，不额外 fetch。

## 操作确认
- `←→` / `Tab` 切换操作，`Enter` 确认，`Esc` 返回；提交和配置返回编辑时保留草稿。
- 提交说明复用底部输入框；仓库读取和写入在后台执行，可继续导航和输入命令。完成结果只更新对应仓库，不替换其他页面或新命令草稿。
- `/cancel` 取消仓库任务，`Esc` 继续负责返回；`Ctrl+C` 退出并取消、回收本界面的任务及 Git 子进程。配置任务仍可用 `Esc` 取消。

## 状态图例
- `✓` 正常　`!` 需关注　`×` 检查失败　`·` 未检查
- `*` 工作区改动，包括未提交、未跟踪和子模块改动；`?` 表示未知。
- 仓库列表展示上次检查结果；文件面板显式读取当前本地状态。
- 无上游分支单独统计，不作为问题，也不会自动发布。
- 同步列合并远程检查与推送结果，优先显示失败和待同步；推送数量为分支数。
- 完整失败原因可在预览和仓库详情中查看。

## 界面语言
- 系统语言为中文时显示中文，其余默认英文。
- 启动前设置 `APP_LANG=en` 或 `APP_LANG=zh` 可覆盖系统语言。
