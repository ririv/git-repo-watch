## 快速导航
- `↑↓` 选择项目，`PgUp` / `PgDn` 翻页。
- 输入为空时，`→` / `Enter` 进入选中项，`←` / `Esc` 返回上一级。
- 有文字时，`←→` 移动光标；`Esc` 先清空输入。
- `Tab` 循环切换仓库、通用设置和定时任务。
- `F1` / `/help` 打开本页，`Ctrl+C` / `/quit` 退出。

## 仓库面板
- 进入仓库后，同时显示概览、分支、工作区文件和提交历史图。
- `/branch` 独立查看分支或聚焦分支面板；输入名称搜索，`Tab` / `Shift+Tab` 筛选全部／本地／远程。
- 分支中 `Enter` 查看引用、提交和上游详情；`*` 标记当前分支，领先／落后基于本地引用，不执行 fetch 或分支写入。
- `Ctrl+S` / `Ctrl+D` 聚焦上个／下个面板，也可点击或在面板内滚动来聚焦。
- `Ctrl+F` 切换当前面板全屏与组合布局。
- 全屏时仍可切换面板，选择、筛选与滚动位置会保留；输入和命令栏始终可用。
- 全屏面板中，`Esc` 先清空输入，再恢复布局；diff 与提交详情仍按原有方式返回。

## 搜索与命令
- 直接打字搜索仓库；文件面板中搜索文件，输入框始终可用。
- `/` 打开输入框上方的全宽命令菜单，`↑↓` 选择、`Tab` 补全、`Enter` 进入。
- `/` 只展示顶层命令；输入 `/diff` 等前缀即显示所有匹配的子命令，不必先输入空格。父命令排在前面。
- 带参数命令直接在输入栏填写，如 `/repo add <path>`、`/settings concurrency <count>`。
- `Ctrl+U` 清空光标前文字，`Ctrl+A` / `Ctrl+E` 跳到开头／末尾。
- 仓库列表中，`Ctrl+F` 切换全部、问题、无上游和推送筛选，`Alt+O` 切换问题优先／路径排序。
- `Ctrl+R` 重新读取报告或刷新文件面板；仓库主列表中的滚轮每次移动三项。

## 路径与补全
- `Tab` 补全光标处的一级目录；唯一匹配补全并追加 `/`，多个匹配显示目录候选。
- 候选中用 `↑↓` / `Tab` / `Shift+Tab` 选择，`Enter` 填入目录后继续编辑，`Esc` 关闭候选。
- `~`、`~/…` 使用当前用户主目录，与应用数据目录无关；确认和执行使用绝对路径。
- 空格和中文按字面处理，可用匹配的单／双引号包裹整段路径，包括 `~/…`。
- 隐藏目录需先输入 `.`；补全仅读取一级目录，并保留光标后的路径。
> 路径是命令后的整段参数。不展开变量、通配符或 Shell 转义；不支持 ~user 用户路径。

## 文件、提交与推送
- `/diff` 打开统一变更界面，同时显示未暂存、已暂存文件及文本／图片预览；选择文件后在后台读取对应版本。
- 宽屏左右排列，窄屏上下排列；`Tab` / `Ctrl+S` / `Ctrl+D` 切换焦点，`Enter` / `→` 聚焦预览，`Ctrl+F` 放大当前面板。
- `Esc` 先清空输入，再恢复放大布局、返回文件焦点；再次按下返回仓库工作区或仓库列表。
- 差异默认在宽屏使用左右对比，窄屏使用统一视图；两侧同步滚动，长行换行后仍保持对应。
- `/diff layout` 打开横向选择器并定位当前设置；`←→` / `Tab` / `Shift+Tab` 切换候选，`Enter` 应用，`Esc` 返回命令草稿。鼠标点击选项只移动候选，仍按 Enter 应用。
- 命令列表标记当前选项，自动模式还显示当前实际的统一／双栏视图，并随窗口大小更新；可点击候选行或按 `Enter` 进入。
- `/diff layout auto`、`/diff layout split`、`/diff layout unified` 立即切换布局，本次 TUI 会话生效；`Tab` 可补全子命令。
- 空输入时 `Space` 勾选，`Insert` 始终勾选，`Ctrl+A` 勾选全部可见项；筛选隐藏文件时保留勾选。
- `/diff stage` / `Alt+S` 暂存全部勾选项，`/diff unstage` / `Alt+U` 取消暂存；未勾选时作用于光标文件。必须先明确选择文件，操作命令不再兼任打开页面。
- 暂存仅接受未暂存项，取消暂存仅接受已暂存项；跨组勾选会明确报错，不修改索引。完成后只刷新当前仓库，保留焦点和新命令草稿。
- 取消暂存保留工作区内容，Git 忽略的文件不列出。
- `/commit` 预览暂存内容，输入说明并确认；保留 Git 钩子和签名。
- `/push` 获取远程并核验上游，确认后仅推送预览过的当前分支快照。
- `/terminal` 在选中仓库打开系统默认终端，可输入 `/te` 后按 `Tab` 补全。

## 图片预览
- 在 `/diff` 中选中 PNG、JPEG、WebP 即预览前后版本；历史详情仍按 `Enter` 查看。按内容识别，不依赖扩展名。
- 宽屏左右对照，窄屏且高度足够时上下排列；较矮面板保留左右对照。保持比例；透明部分显示棋盘背景。
- `Esc` 返回，窗口缩放自动调整；缺失版本、损坏图片和终端不支持像素会明确提示。
- 暂存区与历史图片读取 Git 对象，不用当前磁盘内容代替历史版本。

## 提交历史图
- `/log` 读取本地分支、远程跟踪分支、标签和 HEAD，不进行 fetch。
- `↑↓` / `PgUp` / `PgDn` 选择；`Enter` 进入提交详情，再进入历史文件差异；空输入时 `←` 返回。
- 每页最多 100 个提交，在末尾按 `↓` 或执行 `/log more` 继续加载；`Ctrl+R` 更新引用快照。
- 输入哈希、标题、作者或引用名称定位已加载提交；图节点始终保留，`Tab` / `Shift+Tab` 选择下个／上个匹配。
- `Alt+←→` 平移过宽的图；宽屏显示提交元数据预览。
- 详情中输入文字筛选文件，`Tab` 切换合并提交的父提交，`PgUp` / `PgDn` 滚动提交信息和说明。
- 根提交与空树比较，其他差异明确标出父提交和当前提交；`/diff` 布局命令同样生效。
> 图和历史差异读取不暂存、不提交、不 fetch、不推送，也不改变检查报告。

## 检查与配置
- `/check` 检查当前仓库，`/check all` 检查全部注册仓库；直接开始，无需确认，也不推送。
- 检查在后台进行，可继续浏览、搜索和查看文件；旋转标记指示正在检查的仓库，未完成的保留上轮状态。
- `/cancel` 优先取消当前仓库任务，无当前任务时取消整轮检查；独立仓库并行，共享 Git 存储的操作串行。配置读改写使用短事务。
- `/repo` 管理注册和排除：`/repo add <path>`、`/repo remove`、`/repo exclude <path>`、`/repo unexclude <path>`。
- `/repo scan <path>` 预览发现结果，`/repo import <path>` 注册发现的仓库；扫描遵守 Git 忽略规则。
- `/settings concurrency <count>` 设置有界并发数，范围为 1 至 32。
- `/settings startup-check <true|false>` 控制启动时检查全部仓库，默认 true；修改在下次启动生效。
- `/schedule` 打开任务管理页，查看状态和待应用间隔、修改配置并启停任务。
- `/schedule interval <duration>` 设置间隔，如 6h；`/schedule autopush <policy>` 接受 disabled 或 fast_forward。
- `/schedule apply` 应用配置，`/schedule enable` 启用任务，`/schedule disable` 停止后续调度。
> 自动推送只用于定时检查。启动 TUI 默认后台检查全部仓库，可在通用设置中关闭；不会扫描或推送。启动检查完成后更新整轮报告；暂存、提交和推送只根据本地 Git 状态刷新对应仓库，不额外 fetch。

## 操作确认
- `←→` / `Tab` 切换操作，`Enter` 确认，`Esc` 返回；提交和配置返回编辑时保留草稿。
- 提交说明复用底部输入框；仓库读取和写入在后台执行，可继续导航和输入命令。完成结果只更新对应仓库，不替换其他页面或新命令草稿。
- `/cancel` 取消仓库任务，`Esc` 继续负责返回；`Ctrl+C` 退出并取消、回收本界面的任务及 Git 子进程。配置任务仍可用 `Esc` 取消。

## 状态图例
- `✓` 正常　`!` 需关注　`×` 检查失败　`·` 未检查
- `*` 工作区改动，包括未提交、未跟踪和子模块改动；`?` 表示未知。
- 仓库列表展示上次检查结果；文件面板显式读取当前本地状态。
- 无上游分支单独统计，不作为问题，也不会自动发布。
- 同步列合并远程检查与推送结果，优先显示失败和待同步；推送数量为分支数。
- 完整失败原因可在预览和仓库详情中查看。

## 界面语言
- 系统语言为中文时显示中文，其余默认英文。
- 启动前设置 `APP_LANG=en` 或 `APP_LANG=zh` 可覆盖系统语言。
