## 快速导航
- 在 Git 仓库根目录、子目录或 worktree 中运行 `gw` / `gw tui`，直接打开仓库详情；其它目录打开仓库列表。`gw repos` 始终从仓库列表启动。未登记的仓库只在本次会话打开，不自动登记，也不加入定时执行流程。
- `↑↓` 选择项目，`PgUp` / `PgDn` 翻页。
- 输入为空时，`Enter` 进入选中项，`Esc` 返回上一级。
- 有文字时，`←→` 移动光标；`Esc` 先清空输入。
- `/repos`、`/settings`、`/schedule` 分别打开仓库列表、通用设置和定时任务；`Tab` 不切换这些页面。
- `F1` / `/help` 打开本页，`/quit` 直接退出。`Ctrl+C` 根据当前输入处理：有内容（含命令前缀）时先清空；输入为空时直接提示退出，再按一次才退出。其它按键、粘贴、点击或滚动会解除退出提示。独立的提交说明和指令编辑器保留内容。

- “显示 → 文件图标”控制文件浏览器、工作区与提交详情的文件类型图标，默认开启并保存到 `file_icons`。需要终端支持 Nerd Font 字形；关闭后隐藏图标，目录缩进与文件浏览器的名称对齐保持一致。

- 外部保存、暂存、提交和切换分支会自动刷新本地视图；原生文件观察失败时底部显示原因。自动刷新不访问远程，也不执行工作区操作。

- 冲突恢复操作复用底部输入栏，当前操作和冲突数显示在标题中。Shift+Tab 切换输入与选项模式，←→ 选择继续、跳过、中止，Enter 先预览确认，Esc 返回内容；输入文字切回文件搜索，`/` 切回命令菜单，切换保留草稿且不改变布局高度；未解决并暂存所有冲突时“继续”禁用。
- 冲突文件在同一页显示左（当前）、右（传入）与工作区完整源码。`/repo diff conflict [overview|include-base|base-left|base-right|base-result|left-right|left-result|result-right]` 控制显示：`overview` 显示左／右及下方结果，`include-base` 额外将基础放在最上方；其余六项按名称顺序左右比较指定两份版本。切换保留文件列表、面包屑和输入栏；Tab 补全、Enter 应用。`/focus` 切换区域。双版本独立对齐并同步滚动，各组合分别保留阅读位置；刷新更新结果，Esc 沿用原返回行为。缺失、二进制与超限版本明确标注。输入版本只读，`/editor` 编辑工作区，暂存后使用恢复操作；`/copy` 按焦点复制可见版本或工作区原始源码。

## 鼠标与触控板
- `Ctrl+G` 或全局 `/settings interaction` 选择“交互模式／选字模式”；有上下文时用 `//settings interaction`。`/settings interaction interactive` 与 `/settings interaction text` 可直接切换，保存为偏好并在重启后沿用，设置页也可修改。选字模式由终端处理拖选、复制和右键，程序停用点击、滚动与拖动；原有指针偏好保留。键盘导航、输入、粘贴和命令正常使用，`Esc` 返回当前视图，`Ctrl+C` 沿用上述清空输入和确认退出规则；界面和后台任务正常更新。
- 通用设置中的“鼠标与触控板”分组提供精确点击、滚轮滚动、选择子视图三个独立开关，默认开启，保存后立即生效。
- 左键单击条目进行选择，双击等同于选中后按 Enter，沿用现有确认流程；点击横纵滚动条只定位。标题和空白不触发 Enter，关闭精确点击也会关闭双击。
- 关闭选择子视图后，点击和滚轮只作用于已聚焦面板；关闭滚轮不影响键盘导航。

## 命令目标
- 仓库操作显示本次捕获的仓库和分支，分支在后台读取；长路径中间省略并优先保留文件名，实际操作使用完整路径。

## 外部编辑器
- `/editor` 打开当前选中的仓库、工作区文件或目录，菜单显示目标；历史内容、设置页和空列表不提供可编辑对象。
- `/settings editor` 选择本机检测到的编辑器，`/settings editor git` 跟随当前仓库的 Git 配置，也可输入带参数的命令，如 `/settings editor code --reuse-window`。设置会保存，且不会改动 Git 或 shell 配置。
- 跟随 Git 时优先使用 `GIT_EDITOR`、`core.editor`、`VISUAL`、`EDITOR`，最后使用 Git 编译期默认值。GUI 编辑器独立打开；终端编辑器退出后回到原界面。历史文件预览不提供编辑入口。

## 通用本地操作
- `/terminal` 在当前选择的目录打开终端：选中文件使用其所在目录，仓库或引用视图使用仓库根目录；菜单显示目标。
- `/refresh` 与 `Ctrl+R` 刷新当前视图的本地数据。仓库列表重新读取报告，文件浏览重新读取目录和预览，工作区与分支、历史、stash 列表重新读取本地信息；历史快照不可刷新。

## 仓库面板
- 顶部面包屑显示实际进入路径，首页为“仓库”；打开子视图或详情增加一级，Esc / ← 返回。点击前面的层级可返回并保留选择与搜索；命令草稿和确认操作期间禁用点击导航。
- 聚焦面板增加一级，同级切换替换末级，放大不增加层级。面板根部返回仓库根层，再返回首页。
- 仓库根层用方向键按布局选择面板；Enter 聚焦后才操作内容。选框标出候选面板，聚焦后面包屑增加面板名称。Esc 返回面板选择并保留位置，再按 Esc 返回首页；选框已在左侧一列时，← 也返回首页，右侧一列的 ← 先移到左侧。窄窗口显示当前选择的面板。
- 进入仓库后，同时显示概览、分支、工作区文件和提交历史图。
- `/repo branch` 始终打开完整分支视图；输入名称搜索，`/repo branch filter [all|local|remote]` 筛选全部／本地／远程。
- 分支中 `Enter` 查看引用、提交和上游详情；`*` 标记当前分支，领先／落后基于本地引用，不执行 fetch 或分支写入。
- `/focus` 进入全局聚焦模式，仓库组合界面、diff、文件浏览器共用。方向键按布局切换面板，到边缘停留；Enter／Esc 结束。聚焦模式暂停输入搜索，方向键只切换面板，输入栏明确显示模式；按 `/` 打开全局命令。已有上下文前缀时用 `//focus`、`//zoom` 调用全局命令。结束后恢复直接输入搜索，保留各面板的选择和位置。点击或在面板内滚动也可聚焦。
- `/zoom` 切换当前面板全屏与组合布局。
- 全屏时仍可切换面板，选择、筛选与滚动位置会保留；输入和命令栏始终可用。
- 面板根部的 `Esc` 退出焦点并恢复组合布局，与点击仓库面包屑一致；放大不多占一层返回。`Esc` 仍先清空输入，diff 与提交详情先返回所属面板。

## 拣选与撤销提交
- 在提交历史或提交详情中，执行 `/repo log cherry-pick` 把所选提交的改动带到当前分支，执行 `/repo log revert` 新增反向提交以撤销它。当前历史范围内可直接输入 `cherry-pick` 或 `revert`；拣选支持批量，撤销作用于当前提交。
- 历史默认隐藏复选框。执行 `/repo log select` 进入选择模式后，点击复选框、空输入时按 `Space` 或按 `Insert` 勾选；`select toggle` 切换当前项、`select all` 勾选已加载的匹配提交、`select clear` 清空勾选。`select done` 或空输入时按 `Esc` 退出选择并清空勾选。`Shift+↑↓` 连续扩选／缩选，保留之前的单独勾选；普通移动后可选择新区间。`Enter` 打开已选提交的操作菜单，可拣选、复制提交哈希、清空或退出选择；单选时还可撤销该提交。上下键选操作，`Enter` 确认；鼠标可直接选择。修改仓库前先预览确认，菜单中 `Esc` 返回选择。空选择时提示先勾选。普通浏览的 `Enter` 仍打开详情。输入仍定位提交，选择随预览返回和分页保留，刷新后退出。多条按历史从旧到新排列，最多 512 条。
- 执行前确认目标分支、来源提交和文件列表。批量拣选使用 Git 原生序列，中途冲突会保留后续提交。合并提交单独操作，先选择主线父提交，以它与合并提交的差异为操作内容；撤销时取反。
- 冲突时直接打开变更视图，文件显示为红色 `U`，顶部显示冲突和后续提交数量，并提供继续、跳过、中止按钮。在工作区解决并暂存后执行 `/repo continue`；`/repo skip` 放弃当前提交的冲突处理并跳过，`/repo abort` 放弃本次操作并恢复操作前状态。跳过和中止都需确认。
- 上述恢复命令仅在有未完成的 cherry-pick 或 revert 时显示；重启后仍可识别。完成恢复后，对应失败任务自动标记已处理，历史保留。

## 搜索与命令
- 输入起点的 `/` 打开命令菜单；搜索文字中间的 `/`、`、` 保留为原文，可直接输入目录路径。粘贴完整的 `//命令` 可从已有搜索进入全局命令，关闭菜单后恢复搜索。
- 命令、选项和目录候选均支持 `PgUp` / `PgDn`，按实际可见行数翻页，到首尾停留。选项收起后，空参数按 `Enter` 重新展开，不应用默认值。
- 命令菜单紧贴输入框，快捷键提示在下方。最底部固定预留一行：成功提示显示 5 秒，待处理失败和运行中任务持续显示。输入 `/tasks`、按 `Alt+Enter` 或点击该行打开任务页，返回保留原页面和输入草稿。
- 任务页按待处理失败、运行中、历史排列，保留最近 200 条已结束记录及全部待处理和运行中任务。`Enter` 查看完整详情，`c` 请求取消，`r` 重试手动检查或 fetch，`d` 明确标记失败已处理。查看详情不会清除失败提醒；成功重试才会处理对应原失败。定时检查也会写入任务历史。
- 中文界面默认也可用 `、` 打开命令菜单，沿用当前上下文并显示标准 `/`；`、、` 可进入全局命令。设置中选中“输入 、 打开命令菜单”，按 Enter 直接切换并保存，无需确认；英文界面隐藏且不启用。路径、提交信息等正文中的顿号保持原样。
- 普通输入默认过滤列表，只保留匹配项；输入框标题显示当前方式和搜索对象。
- 有底部选项时，`Shift+Tab` 切换输入与选项模式，保留草稿和布局高度；`Tab` 只补全命令和参数。选项模式用方向键选择、Enter 确认，Esc 或直接输入返回编辑；没有选项时不切换。内容面板通过 `/focus` 切换。
- 搜索栏为空时 `/` 打开当前视图的全宽命令菜单，`↑↓` 选择、`Tab` 补全、`Enter` 进入；`//` 直接打开全局命令。
- 命令支持按名称或中英文提示说明筛选，英文不区分大小写，如 `/终端`、`/频率`、`/live diff`；名称匹配优先，Tab 补全选中项的实际命令。
- 全局菜单只展示顶层命令；输入 `/repo diff` 等前缀即显示所有匹配的子命令，不必先输入空格。展开命令组时，当前层入口优先，更深的子操作随后显示；继续输入仍搜索全部子命令。
- 当前视图内暂时不可用的命令和选项仍在原位置，以灰色显示原因；Enter 或点击保留草稿，不启动操作。没有进行中的操作、未选提交或已处于目标显示方式时也遵循此规则。历史 diff 的工作区操作、不支持预览的文件切换，以及关闭后的 AI 功能仍隐藏。暂存、复制和拣选等操作在候选行显示实际文件、行或提交数量。
- 带参数命令直接在输入栏填写，如 `/repos add <path>`、`/settings concurrency <count>`。
- `[tree|flat]` 表示可选的固定选项，`<path>`、`<name>` 表示自行输入。选项按可用宽度完整显示，放不下时按完整选项以 `…` 简写，补全菜单始终展示完整范围；`[<model>|default]` 表示模型名或特殊值 `default`。
- `/repo diff view` 切换目录树／平铺列表，默认展开目录树；也可执行 `/repo diff view tree` 或 `/repo diff view flat`。选择保存为偏好，下次启动沿用。单一子目录链合并显示（如 `output/imagegen/`）；文件夹也能定位和勾选，文件可预览差异。
- `Ctrl+U` 清空光标前文字，`Ctrl+A` / `Ctrl+E` 跳到开头／末尾。
- 仓库首页可点击顶部“筛选”和“排序”的文字或当前值，展开对应选项；也可用 `/repos filter [all|problems|…]` 筛选、`/repos sort [priority|name|…]` 排序。菜单定位当前值，选择后才应用；按参数名或中英文说明筛选，`↑↓` 选择、Tab 补全、Enter 应用、Esc 收起，✓ 标记当前值。关闭精确点击或启用选字模式时使用命令操作。
- 自动推送策略和 AI 工具也使用同一参数菜单：空格或 Enter 展开，↑↓ 选择、Tab 只补全、Enter 提交所选值。配置确认沿用原有规则，取消不写入。
- 筛选：all 全部、problems 问题、clean 正常、failed 检查失败、unchecked 未检查、no-upstream 无上游、pushes 有推送记录。
- 排序：priority 状态优先、name 名称升序、path 路径升序、updated 最近更新（未检查排最后）；可直接执行，如 `/repos sort name`；排序保存为偏好，下次启动沿用。
- 筛选与文字搜索同时生效；首页已有搜索时按 `/` 打开命令，应用或关闭后恢复搜索，保留仍可见的选中仓库。筛选与搜索只影响当前会话，不检查仓库或修改报告。
- `Ctrl+R` 重新读取报告或刷新文件面板；仓库主列表中的滚轮每次移动三项。

## 过滤与定位
- 全局 `/search` 展开当前视图支持的方式并标记当前值；`/search filter` 过滤，`/search locate` 定位。在带上下文前缀的视图中用 `//search` 打开此全局命令。
- 仓库、工作区、分支、stash 与历史提交的文件列表支持两者，默认过滤。切换保留关键词和仍可见的当前选择；每个列表分别记住本次会话的方式。
- 定位保留完整列表，匹配文字用琥珀底色和下划线标记，当前匹配加强底色、加粗并使用亮色下划线，保留语法和状态颜色；有关键词时 `↑` / `↓` 循环选择上一个／下一个匹配，输入框显示当前匹配序号和总数。没有匹配时显示 `0/0`，保留原选择。清空关键词后方向键恢复逐行移动。
- 提交历史图只支持定位，搜索范围是已加载提交，保留所有连线；需要搜索更早提交时先加载更多。文件树只支持后台过滤整个仓库的路径；聚焦文本内容时只支持定位，图片和二进制说明不提供定位。
- 设置、概览、帮助、只读详情以及差异的内容预览只提供命令输入，不搜索隐藏列表，也不提供搜索方式命令。切回列表恢复原搜索词，键盘、点击和滚轮切换焦点时行为一致。搜索与状态筛选、排序、文件勾选分别管理。

## 上下文前缀
- `/repo diff`、`/repo log`、`/repo branch`、`/repo stash` 打开完整视图；返回恢复来源焦点和选择。子面板中按 `/` 只提供焦点上下文，不改变布局。设置、定时任务和帮助返回时也恢复来源。
- 当前视图前缀独立显示，可按段选择和编辑：文件／差异为 /repo diff，历史为 /repo log，分支为 /repo branch，管理页为 /repos、/settings、/schedule。首页使用全局 /，概览使用 /repo，stash 使用 /repo stash。
- 只输入前缀后的操作，如 diff 中的 stage、unstage、layout、refresh；候选只在当前范围内按名称或中英文说明筛选。
- 后缀为空时，Backspace 先选中末段，例如 `/repo branch` 只选中 `branch`。← 向左扩选一段，→ 缩回一段；末段再按 → 取消选择。输入或粘贴普通文字只替换选中部分，如 `branch` 换为 `log` 后得到 `/repo log`；带 `/` 或 `//` 的粘贴使用全局命令。候选跟随保留的父级，全选时显示全局候选；↑↓ 选择、Tab 补全，点击执行。选中部分沿用原来的反色样式，未选中部分不变。
- 空命令后缀再按 / 也会切到全局；从搜索状态输入 //settings 可直接打开全局设置。
- Backspace / Delete 删除当前选区，保留未选中的父级；删除整个前缀才关闭命令。Enter 或 Esc 取消选区并恢复原前缀，不执行候选；未选择前缀时 Esc 关闭命令并恢复搜索。编辑不离开视图或切换仓库，仓库目标和复制内容保持打开命令时的快照，下次打开才按当前焦点重新确定前缀。
- 已有搜索时可先 Home 再 / 打开命令，路径中间的 / 仍作为搜索文字。
- 历史差异提供布局与复制，不提供工作区暂存或刷新；目录补全、配置确认及布局选择器返回后保留前缀、草稿和光标。

## 复制当前选择
- 一级 `/copy` 复制当前选择，候选标签显示实际内容；仓库相关上下文菜单可直接输入 `copy` 筛选。`/refresh`、`/terminal`、`/editor` 同样显示完整命令名，Tab 切到全局，Enter 执行。没有可用对象时置灰。
- 文件列表的 `/copy` 复制勾选路径，未勾选则复制当前行；多项按行分隔、路径去重，使用相对路径并保留中文与空格。
- diff 预览的 `/copy` 复制当前文件的原始补丁；不包含展示行号、颜色或布局换行，不重新读取 Git。
- 历史图的 `/copy` 复制完整提交 ID；提交详情中则复制当前历史文件路径，进入历史 diff 后使用 `/copy`。
- 分支中的 `/copy` 复制选中分支名称；错误页执行 `/copy` 复制完整错误。
- 组合面板跟随焦点；读取失败的预览或面板复制其错误详情。打开命令时固定仓库和选择，后台刷新不会改变复制目标。
- 图片、尚未加载、空白或已截断的补丁明确报错；剪贴板后台写入，成功后才提示，不阻塞导航，也不覆盖新命令。
- Linux 需 X11 或支持 data-control 的 Wayland 会话；退出后保留剪贴板内容取决于桌面剪贴板管理器。错误页只开放复制与退出命令。

## 路径与补全
- `Tab` 补全光标处的一级目录；唯一匹配补全并追加 `/`，多个匹配显示目录候选。
- 候选中用 `↑↓` 选择，`Tab` / `Enter` 填入选中目录后继续编辑，`Esc` 关闭候选。继续输入会筛选当前目录候选。
- 目录、分支和 stash 补全在后台读取；快速切换命令或编辑路径会取消旧请求，迟到结果不会覆盖新草稿。读取超过短暂等待后才显示提示。
- 开启精确点击时，也可单击目录候选填入路径；填入后继续编辑，再按 `Enter` 才预览操作。
- `~`、`~/…` 使用当前用户主目录，与应用数据目录无关；确认和执行使用绝对路径。
- 空格和中文按字面处理，可用匹配的单／双引号包裹整段路径，包括 `~/…`。
- 隐藏目录需先输入 `.`；补全仅读取一级目录，并保留光标后的路径。
> 路径是命令后的整段参数。不展开变量、通配符或 Shell 转义；不支持 ~user 用户路径。

## 分支、拉取与 stash
- `/repo branch create <name>` 在当前提交创建本地分支，不切换；`/repo branch switch <name>` 切换已有本地分支。切换前要求已跟踪文件干净，不覆盖未跟踪文件，也不切换其他 worktree 占用的分支。
- `branch switch` 的空格后显示本地分支名与提交摘要；输入筛选，↑↓ 选择，Tab 填入名称，Enter 预览。补全不读取远程跟踪和领先／落后统计。
- `/repo fetch` 立即在后台获取已配置的远程跟踪分支，遵守 refspec、排除与 skipFetchAll 设置，不改工作区或推送。
- `/repo pull` 获取一次远程，预览固定的上游提交，确认后仅快进；分叉或脏工作区明确报错，不自动 merge、rebase 或 stash。
- 同步预览在底部单行显示实际阶段；后台任务详情单独展示阶段耗时，失败原因保持独立。
- `/repo sync` 更新远程状态，预览当前分支需要的快进拉取或推送，确认后执行；已同步时直接提示。分叉时提示先合并或 rebase；未配置远程或远程上游时提示当前无法同步，不记为仓库失败。结果在后台任务中查看。
- `/repo stash` 打开独立列表；↑↓选择、Enter 查看详情、←/Esc 返回。进入后 `/` 使用 /repo stash 上下文，列表可搜索消息和对象 ID。
- `/repo stash save [tracked|all|selected]` 保存改动。不填参数时显示选项菜单，Tab 补全、Enter 选择；`selected` 显示勾选文件数，没有勾选时置灰。

Stash 列表按 Enter 打开内容：顶部为保存说明，左侧为文件列表，宽屏右侧连续显示差异；选择文件自动定位，Enter 打开完整 diff，Esc 返回并保留选择与搜索。窄屏先选文件再按 Enter 查看。详情中 `/focus` 切换面板，`/focus` 和 `/zoom` 沿用共用面板操作。

`/repo stash scope [all|staged|unstaged]` 选择查看范围：`all` 为保存基准到保存时工作区的最终差异，含保存的未跟踪文件；`staged` 为原暂存改动；`unstaged` 为原未暂存改动，含保存的未跟踪文件。所有内容取自保存快照。暂存后又改回基准的文件，可在后两种范围中查看。
- `tracked` 保存整个仓库已跟踪文件的暂存、未暂存改动，也包含已经 git add 的新文件；`all` 额外包含未跟踪文件。`selected` 仅保存工作区勾选文件的暂存、未暂存改动及所选新文件，重命名同时处理旧、新路径；目标取打开命令时的勾选快照。三种均不包含未跟踪的忽略文件。
- 保存页显示范围与实际路径；说明可留空，使用 Git 默认说明。Shift+Tab 切换输入与选项模式；←→ 选择保存或取消；Enter 确认当前项，Esc 返回原命令；PgUp/PgDn、滚轮和滚动条查看文件列表。按钮单击选择，双击与 Enter 一致。取消不保存改动。
- `/repo stash apply <stash-id>` 恢复并保留；`/repo stash pop <stash-id>` 恢复成功后删除；`/repo stash drop <stash-id>` 只删除，不恢复。选中列表项后补全这些命令会填入其完整对象 ID，仍需确认。
- stash 参数候选显示索引、短 ID 和说明，可按说明或 ID 筛选；Tab 填入完整对象 ID，Enter 或点击候选预览操作，确认后才修改仓库。
- `/copy` 复制选中 stash 的完整对象 ID；`/refresh` 刷新列表。恢复发生冲突时报告失败，保留原 stash 与实际冲突状态。
- 写操作先预览再确认，返回编辑保留完整草稿。确认时重新核验 HEAD、索引、工作区和目标引用；stash 还核验列表顺序，外部变更会要求重新预览。

## 链接与路径
- 带下划线的网址与路径可直接单击打开；网址使用默认浏览器，本地文件与文件夹使用系统默认应用。沿用精确点击设置，列表选择、目录开合与滚动条保持原有行为。
- Markdown 链接文字保留原始目标，相对文件链接以当前文档所在目录为基准，支持中文、空格与百分号编码；滚动、换行和分屏不会截断目标地址。
- 选字模式由终端处理原生链接。Ghostty 的 macOS 界面通常使用 `⌘` 点击，Linux 使用 `Ctrl` 点击，具体行为遵循终端设置。
- 打开操作在后台执行；失败会显示原因，文件不存在时不会改为打开其它位置。

## 文件浏览
- 文件树中的长名称和路径支持横向滚动，底部边框只在溢出时显示滚动条，右侧 Git 状态保持固定。使用触控板横向滚动、`Shift` 加滚轮，或点击／拖动滚动条；路径过滤时同样可用。空输入时 `←→` 横向滚动；输入文字时左右键编辑光标。
- `/repo files` 浏览已跟踪文件和未被 Git 忽略的未跟踪文件；目录逐层后台加载，`.git` 不显示。
- 浏览区顶部显示目录面包屑，文件名在路径末尾以亮白色加粗显示，内容面板不再重复文件名标题。单击父目录返回文件树中的对应位置，单击仓库名返回根层；路径过滤会清空，已有展开状态及各文件的定位词、滚动位置保留。窄窗口省略中间目录，极矮窗口保留内容区域。
- 只有一个子目录、没有其它可见条目的连续目录合并成 `父目录/子目录/` 一行；遇到文件或分叉停止合并。
- `↑↓` 选择，`Enter` 展开或折叠目录，文件选中后自动预览，`Enter` 聚焦预览。`←→` 横向滚动，`/focus` 切换面板，`Esc` 返回。
- 单击目录行展开／折叠，双击只切换一次；文件单击选中，双击聚焦预览。遵循精确点击设置，点击滚动条只定位。
- `/focus` 切换文件树和预览，`/zoom` 放大当前面板；窄窗口直接显示当前面板。预览支持语法高亮、图片、纵向及横向滚动。
- 输入关键词在后台搜索整个仓库的路径，最多显示 1,000 项；`Esc` 先清空搜索，再返回文件树或来源视图。
- `/repo files diff` 查看选中文件的改动，返回保留文件树与选择；`/refresh` 刷新目录与预览，`/copy` 复制选中路径。
- 行尾固定两列显示文件状态：左侧索引、右侧工作区；`M` 修改、`A` 新增、`D` 删除、`R` 重命名、`T` 类型变化，`??` 未跟踪、`UU` 冲突。
- Markdown、SVG 默认以源码打开，通过命令菜单切换源码、渲染预览与分屏。普通文件不显示这些切换命令。
- `/repo files mode [source|preview]` 选择当前文件的源码或渲染预览；不填参数时展开同一组选项，用 ✓ 标记当前值，Tab 补全、Enter 应用，Esc 取消。已处于目标模式的选项置灰并说明原因。`/repo files layout [single|split]` 选择单栏或分屏，同样支持选项菜单；重复选择当前布局保持原状；分屏中选择 source 或 preview 返回对应单栏。各文件分别记住显示方式与两侧滚动位置，直到退出当前会话。
- 分屏时，`/focus` 在文件树、源码、预览之间切换；点击或滚动可聚焦对应一侧，沿用指针设置。窄窗口上下排列，最小窗口只显示当前焦点，恢复尺寸后保持分屏。
- SVG 由 resvg 在后台按窗口尺寸渲染，支持内嵌资源；引用外部图片会明确报错。Markdown 复用帮助页的终端排版，图片保留说明与地址。

- 文件内容中输入文字定位，`↑↓` 循环切换每处匹配，标题显示序号／总数；忽略英文大小写，支持中文。高亮保留语法颜色和链接，行号不参与匹配；长行、自动换行和缩放都会将当前匹配带入视口。`Esc` 先清空定位词，再返回文件树。树的过滤词、源码和 Markdown 预览的定位词分别保存；分屏定位作用于当前一侧。

## 文件、提交与推送
- `/repo diff` 打开统一变更界面，同时显示未暂存、已暂存文件及文本／图片预览；选择文件后在后台读取对应版本。
- 宽屏左右排列，窄屏上下排列；`/focus` 切换焦点，`Enter` / `→` 聚焦预览，`/zoom` 放大当前面板。
- `Esc` 先清空输入，再恢复放大布局、返回文件焦点；再次按下返回仓库工作区或仓库列表。
- `/repo diff context [full|changes]` 切换完整源码／仅差异，默认完整源码，选择保存并在重启后沿用；与双栏／统一布局独立。暂存后保留源码和阅读位置，清空已消失的选区，通过方向键或点击选择下一处改动。复制仍为原始补丁。
- 差异默认在宽屏使用左右对比，窄屏使用统一视图；两侧同步滚动，长行保持一行，横向同步平移。
- `/repo diff header [show|hide]` 选择显示／隐藏原始 Git 文件头；不填参数时显示选项菜单，重复选择当前值保持原状。默认收起，切换文件、视图及重启后沿用，收起时恢复原阅读位置。路径与对象 ID 从正文隐藏，文件模式变化和相似度显示在信息区；变更块标题与二进制提示仍保留，缺少末尾换行时，在对应末行下方用独立的红色 `⊖` 标记，行号留空，不参与按行选择；双栏只标记缺少换行的一侧。复制差异始终保留完整原始补丁。
- `/repo diff layout` 不带参数时按 Enter 打开横向选择器，末尾空格不改变入口；开始输入参数时显示可补全的选项。选择器定位当前设置，`←→` 切换候选，`Shift+Tab` 返回输入，`Enter` 应用，`Esc` 返回命令草稿。鼠标单击选项只移动候选，双击或按 Enter 应用。
- 命令列表标记当前选项，自动模式还显示当前实际的统一／双栏视图，并随窗口大小更新；可点击候选行或按 `Enter` 进入。
- `/repo diff layout auto`、`/repo diff layout split`、`/repo diff layout unified` 立即切换布局，保存为偏好，下次启动沿用；这些值是布局参数；空格后自动显示候选，`Tab` 补全参数。
- 目录单击或按 `Enter` 展开／收起，文件单击定位、双击进入；点击复选框勾选／取消；沿用设置中的精确点击开关。空输入时 `Space` 勾选，`Insert` 始终勾选，`Ctrl+A` 勾选全部可见文件；筛选隐藏文件时保留勾选。目录勾选作用于本区域内符合筛选的所有后代文件，包含折叠隐藏的文件，`✓` 表示全部勾选，`−` 表示部分勾选。
- 文件焦点下，`/repo diff stage` 暂存全部勾选项，`/repo diff unstage` 取消暂存；未勾选时作用于光标文件或目录内符合筛选的文件。
- 预览焦点下默认按块选择，`↑↓` 切换块；`/repo diff select [hunk|line]` 切换粒度。按行时 `Shift+↑↓` 扩选／缩选连续的变更行，单击变更行可定位。统一、双栏和自动换行使用同一选区；`PgUp/PgDn` 和滚轮只滚动预览。
- 选区在行号区显示蓝色高亮，分隔线统一使用细线 `│`，选中时一起标蓝；代码区保留增删底色和语法颜色。双栏两侧分别标记，换行续行延续标记。选中后通过暂存、取消暂存或丢弃操作执行。
- 预览焦点下，空输入时 `Space` 暂存所选未暂存改动，或取消暂存所选已暂存改动；`stage`／`unstage` 同样只处理选区。`/repo diff discard` 显示丢弃所选未暂存改动的确认页，默认返回，确认后执行。
- 部分操作支持普通文本及新增／删除文件；重命名、冲突、符号链接、子模块、二进制、截断差异和外部内容过滤器不支持。无法独立应用的行要求扩大选区；文件或索引已变化时要求刷新后重新选择。历史差异只读。
- 暂存仅接受未暂存项，取消暂存仅接受已暂存项；跨组勾选会明确报错，不修改索引。完成后只刷新当前仓库，保留焦点和新命令草稿。
- 取消暂存保留工作区内容，Git 忽略的文件不列出。
- `/repo commit` 上方预览暂存内容，下方编辑多行说明；`Enter` 换行、`↑↓` 移动光标，`Shift+Tab` 切换说明与底部横向选项。操作栏用 `←→` 选择、`Enter` 执行、`↑` 返回编辑；选择底部的提交后直接执行，不重复预览，`Ctrl+S` 也可提交，`PgUp/PgDn` 查看暂存内容；保留 Git 钩子和签名。
- `/repo push` 核验后直接普通推送；远程有本地不包含的提交时，单独确认后通过 `--force-with-lease` 强推，默认选中取消。未配置上游时选择远程并输入目标分支名，Enter 发布，成功后保存上游；Git 配置 `push.autoSetupRemote=true` 且默认目标明确时自动发布同名分支。定时流程仍只允许普通推送。
- `/terminal` 在选中仓库打开系统默认终端，可输入 `/te` 后按 `Tab` 补全。

## 图片预览
- 在 `/repo diff` 中选中 PNG、JPEG、WebP 即预览前后版本；历史详情仍按 `Enter` 查看。按内容识别，不依赖扩展名。
- 宽屏左右对照，窄屏且高度足够时上下排列；较矮面板保留左右对照。保持比例；透明部分显示棋盘背景。
- `Esc` 返回，窗口缩放自动调整；缺失版本、损坏图片和终端不支持像素会明确提示。
- 暂存区与历史图片读取 Git 对象，不用当前磁盘内容代替历史版本。

## 提交历史图
- `/repo log` 读取本地分支、远程跟踪分支、标签和 HEAD，不进行 fetch。
- `↑↓` / `PgUp` / `PgDn` 选择；`Enter` 进入提交详情，再进入历史文件差异；空输入时 `Esc` 返回。
- 每页最多 100 个提交，在末尾按 `↓` 或执行 `/repo log more` 继续加载；`Ctrl+R` 更新引用快照。
- 输入哈希、标题、作者或引用名称定位已加载提交；图节点始终保留，`↑` / `↓` 循环选择上个／下个匹配。
- 输入框为空时 `←→` 横向滚动过宽的图线或文字，短哈希固定；宽屏显示提交元数据预览。
- 提交详情顶部显示说明与元信息，左侧列出变更文件，宽屏右侧连续展示所有文件的统一 diff。选择文件会定位到对应差异，`Enter` 打开该文件的完整 diff，返回保留选择和位置；窄屏隐藏连续预览。
- 文件面板中输入文字筛选或定位，`/repo log parent` 切换合并提交的父提交。滚轮分别滚动说明、文件列表和差异；`/focus` 切换面板，`/zoom` 放大或还原，聚焦说明或差异时 `↑↓` / `PgUp` / `PgDn` 滚动内容。
- 根提交与空树比较，其他差异明确标出父提交和当前提交；`/repo diff` 布局命令同样生效。
> 图和历史差异读取不暂存、不提交、不 fetch、不推送，也不改变检查报告。

## 远程获取与配置
- 启动时默认只读取本地状态。`/settings startup-fetch [true|false]` 控制下次启动是否后台 fetch 一次；覆盖已管理仓库和当前会话仓库，共用手动获取逻辑，不执行定时流程中的 pull、push。
- `/repo fetch` 获取当前仓库的远程信息并刷新状态；`/repos fetch` 获取全部已管理仓库的远程信息。
- 检查在后台进行，可继续浏览、搜索和查看文件；旋转标记指示正在检查的仓库，未完成的保留上轮状态。
- `/cancel` 优先取消当前仓库任务，无当前任务时取消整轮检查；独立仓库并行，共享 Git 存储的操作串行。配置读改写使用短事务。
- `/repo` 打开选中仓库，`/repos` 返回列表；`/repos manage` 管理已添加的仓库。`/repos add <path>` 添加单个仓库，`/repos remove` 移除当前注册项。
- `/repos scan <path> [--exclude <path>…]` 扫描后勾选要添加的仓库，确认“添加选中”后保存。已添加项单独标明；读取失败项不能添加，可查看原因。`Space`／`Insert` 勾选，`Ctrl+A` 全选匹配的新仓库，`Shift+Tab` 切换输入与选项，`Enter` 执行，`Esc` 返回。
- 一个 `--exclude` 可跟多个目录，如 `/repos scan ~/Proj --exclude backups archive "归档 项目"`。相对路径以扫描起点为基准，路径逐个支持 Tab 补全。排除和取消勾选均仅本次生效，不保存长期规则。
- `/settings concurrency <count>` 设置有界并发数，范围为 1 至 32。
- 流程编辑页勾选步骤即可加入，取消勾选即可移除；`↑↓` 选择步骤与底部保存、取消，`Enter`／空格操作当前项，`←→` 选择独立“操作”面板中的上移、下移。点击步骤也可直接勾选，保存后生效。
- `/settings wrap [true|false]` 设置文件文本与 diff 的自动换行，默认关闭并保存到配置。开启后行号固定，双栏 diff 保持前后版本对齐，链接仍可点击；关闭时使用横向滚动。也可在设置页的“显示”组修改。
- `/schedule` 打开定时任务页。状态、间隔、时间基准和执行流程各自显示当前值与对应按钮，单击按钮即可修改或进入启停确认；↑↓ 选择，Enter 操作。
- `/schedule actions` 编辑执行流程；`/schedule interval <duration>` 设置间隔，如 6h。
- `/schedule anchor <datetime|auto>` 设置本地时间基准，可填 HH:MM[:SS] 或 YYYY-MM-DD HH:MM[:SS]；auto 在启用时重新生成。
- 基准缺省时，首次启用会自动生成并保存，后续启停和重启沿用；定时任务页显示基准与当前已应用任务的下次触发。
- 间隔支持 s / m / h / d / w（秒、分、小时、天、周，至少 60 秒），保存后用 `/schedule apply` 应用。
- `/schedule apply` 应用配置；`/schedule enabled [true|false]` 选择启用或停用，不填参数时显示选项菜单并标记当前状态，确认后执行。
> 定时流程默认 fetch → inspect；可添加 pull、push 并调整顺序。inspect 固定最后，push 前先 fetch 或 pull。某步失败即停止此仓库的后续步骤，详情保存在后台任务中。手动检查仍只执行 fetch 和本地读取。

## 操作确认
- `←→` / `Tab` 切换操作，`Enter` 确认，`Esc` 返回；提交和配置返回编辑时保留草稿。
- 提交说明复用底部输入框；仓库读取和写入在后台执行，可继续导航和输入命令。完成结果只更新对应仓库，不替换其他页面或新命令草稿。
- `/cancel` 取消仓库任务，`Esc` 继续负责返回；确认 `Ctrl+C` 退出或执行 `/quit` 时取消、回收本界面的任务及 Git 子进程。配置等阻塞操作执行期间，`Esc` / `Ctrl+C` 只请求取消并等待子进程结束，不进入退出确认。

## 状态图例
- 绿色 `✓` 正常　黄色 `!` 需关注　红色 `×` 失败　灰色 `·` 未检查；旋转标记表示执行中。顶部统计与列表标记一致，实际失败优先，且各仓库只计入一类；详情保留各分支的成功与失败结果。
- `*` 工作区改动，包括未提交、未跟踪和子模块改动；有改动或当前分支同步提交数非零时归入黄色“需关注”，仓库名保持原色。其它分支的差异不影响首页分类。`?` 表示未知。
- 仓库列表展示上次检查结果；文件面板显式读取当前本地状态。
- 首页右侧详情在同步信息上方显示当前分支，与同步数来自同一份快照；无远程时也显示分支名。尚无提交时显示 HEAD 指向的分支名，游离时显示“游离 HEAD”，没有快照时显示 ?。窄屏可进入仓库概览查看分支。
- 无上游分支单独统计，不作为问题，也不会自动发布。
- 首页同步列显示当前检出分支相对其上游的 ↑领先提交数、↓落后提交数，其它分支在仓库详情与分支面板中查看。没有上游、上游引用缺失、HEAD 游离或尚无提交时显示 —，且这些情况不会单独触发“需关注”；旧记录缺少当前分支数据时显示 ?，重新检查后更新。`problems` 筛选包含需关注与失败，`failed` 只包含失败。推送结果在任务记录与详情中查看。
- 完整失败原因可在预览和仓库详情中查看。

## 滚动与位置提示
- 横纵滚动条支持点击轨道定位、按住滑块拖动，拖出轨道仍作用于原面板，松开结束；沿用精确点击开关。
- 纵向滚动条嵌在右边框，只覆盖实际内容行，避开固定表头；未暂存与已暂存各有自己的轨道。内容未超出时不显示。
- 仓库根层用方向键选择面板；已聚焦内容中用全局 `/focus` 切换面板，左右键保留内容本身的操作。
- diff 预览中，空输入时 `←→` 横向滚动长行，行号和增删标记固定，双栏同步平移；`Esc` 返回。长行不自动换行，超宽时底边框显示滚动条，不额外占用内容行。
- 历史列表用 `←→` 统一横向滚动图线、引用和提交标题，各部分只在超宽时滚动，短哈希固定；`Enter` 打开详情，`Esc` 返回。
- 也支持横向滚轮或 `Shift` + 竖向滚轮，需终端转发相应事件。输入有文字时，左右键仍移动输入光标；命令和确认选择器不受影响。
